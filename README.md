# Calculadora de Preços Comerciais

![](https://i.imgur.com/6Oi0NvX.png)

## O que é um preço comercial?
Preço comercial é um preço atrativo para o cliente considerando um preço arredondado sem números quebrados ou que instigua um preço menor. Como os preços "99,9". 

## Como este programa funciona?

### Cálculo de Preço Comercial

Este programa é uma calculadora que facilita na criação de preços comerciais para marketplaces principalmente inspirado na forma de precificação do Mercado Livre, onde podemos oferecer um preço a partir de um desconto por porcentagem. 

A calculadora facilita ao dar três opções de margem de desconto e faz automaticamente o cálculo para qualquer valor numérico que o usúario solicita.

Por exemplo: Caso o usuário queira colocar em seu produto o valor 39,9, ele insere o valor no programa, seleciona qual porcentagem de desconto ele quer, e o programa calcula **qual** valor **menos** a porcentagem escolhida daria o valor de **39,9**. Assim quando ele colocar o valor no Mercado Livre e oferece uma promoção igual a porcentagem escolhida ele terá o valor de 39,9 como valor *por* (valor final) como desejado para precificação no Marketplace.

### Cálculo de Envio de Estoque

A calculadora também conta com uma forma de realizar o cálculo de envio de produtos para o full. Full é o sistema de entregas rápidas do mercado livre, os vendedores enviam seus estoques para agências do mercado para aumentar a velocidade nas entregas. É importante manter este estoque abastecido de acordo com a relação de vendas e semanas. 

O programa traz esse cálculo embora simples, mas que ainda toma tempo, de forma automatizada. Onde é calculado quanto de estoque se deve enviar dependendo das semanas escolhidas, se necessita de estoque para as próximas 6 semanas é calculado vezes a quantidade de vendas nos últimos setes dias, para que o vendedor não corra o risco de ficar sem estoque e perder vendas.

### Como usar

*O programa não possui licença, o windows defender pode detectar um falso positivo, coloque ele nas exceções*

![](https://i.imgur.com/ndyS7X7.png)

- **Campo 1:** Campo para selecionar qual será a porcentagem de cálculo para desconto.

- **Campo 2:** Insira o valor desejado *ex: 39,9; 59,9; 289,9*.
- **Campo 3:** Clique em 'calcular' para realizar o cálculo comercial.
- **Campo 4:** O resultado aparece neste campo, esse é o valor **de** que ao ser retirado a porcentagem dá o valor do campo 2, este valor que é inserido no marketplace.
- **Campo 5:** Botão para copiar o resultado no campo 4.
- **Campo 6:** O resultado de quanto fica o valor do campo 2 com 3% de desconto para ofertas de marketplace.
- **Campo 7:** Campo para selecionar o valor de quantas semanas de estoque gostaria de cobrir.
- **Campo 8:** Insira o valor de vendas realizadas nos últimos 7 dias.
- **Campo 9:** Clique no botão 'full' para realizar o cálculo do full.
- **Campo 10:** O resultado de quantas unidades devem ser enviadas aparece nesse campo.
- **Campo 11:** Botão para limpar os campos.
- **Campo 11:** Botão para exportar o histórico das suas operações em um arquivo excel.
